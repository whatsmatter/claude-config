# OhMyPack — Strapping Machine Repair Google Ads Campaign

Content library and setup playbook for the "ซ่อมเครื่องรัดกล่อง" (strapping/box-strapping machine repair) Google Ads campaign for OhMyPack.

## When to use this

Trigger for any request involving:
- Building or launching this Google Ads campaign
- Writing/selecting Thai RSA headlines, descriptions, callouts, sitelinks, or snippets for it
- Keyword or negative-keyword planning for "เครื่องรัดกล่อง" repair intent
- Reviewing or troubleshooting existing ads/keywords for this campaign
- Any mention of OhMyPack + ซ่อมเครื่องรัดกล่อง together

## Positioning (read first — this shapes every piece of copy)

- **Lead with speed + genuine parts + a loaner machine during repair.** Do NOT lead with warranty length as the main selling point — competitor WePackage offers 6–12 months warranty vs OhMyPack's 3 months, so a direct warranty comparison loses.
- **Keyword strategy has 3 tiers:**
  1. **Head terms** — ซ่อมเครื่องรัดกล่อง + price/parts intent
  2. **Brand/model** — CHALI JN-740, WE-801, etc.
  3. **Symptom-based** (highest intent, least competition) — ไม่ตัดสาย, รัดไม่แน่น, ไม่ฟีดสาย, บอร์ดเสีย
- Symptom-based keywords should get priority budget — see setup guidance below.

## Content library

All ready-to-use content — keywords with match types, negative keywords with rationale, 15 RSA headlines, 15 RSA descriptions, 15 long descriptions (for Performance Max/assets), 15 callouts, 15 opening lines, 15 explanation lines, 15 sitelinks with URL paths, and 15 structured snippets — is in `reference.md`. Read that file before writing or selecting any copy so output matches the approved set exactly (character limits included: headlines ≤30 chars, descriptions ≤90 chars, callouts ≤25 chars).

Don't invent new copy variants unless the user explicitly asks for fresh options — first check whether `reference.md` already has something that fits.

## Campaign setup guidance

1. **Week 1:** Split into 3 ad groups (head terms / brand-model / symptoms). Set manual CPC cap ~฿35. Launch with Phrase + Exact match only initially.
2. **Allocate 40% of budget to the symptom-based ad group** (ไม่ตัดสาย / รัดไม่แน่น / ไม่ฟีดสาย) — highest intent, lowest competition.
3. **Set up conversion tracking before launch:** phone calls from ads, LINE @ohmypack clicks, form submissions.
4. **Ad schedule:** Mon–Sat 08:00–18:00, weighted toward B2B hours.
5. **Once conversions hit ≥15–20/month:** switch bidding strategy to Maximize Conversions.
6. **Weekly:** check the Search Terms Report and add irrelevant queries as negative keywords.

## Important caveats to flag to the user

- Never make warranty length the primary headline — it's a losing comparison vs WePackage.
- Any headline near the 30-character limit needs a manual double-check in Google Ads Editor before publishing.
- Before using "มีเครื่องสำรองให้ใช้ระหว่างซ่อม" (loaner machine) or "ซ่อมเสร็จใน 48 ชม." (48-hour turnaround) claims, confirm with the user these are still current/accurate offers.
- Recommend the user verify real search volume via Google Keyword Planner before locking in budget.
